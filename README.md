# Captures de la newsletter GET17

**Dépôt PUBLIC**, servi par GitHub Pages : `https://edwinparis-rgb.github.io/get17-email-captures/AAAA-MM/<fichier>`.

Il contient **uniquement des captures d'écran de démonstration** insérées dans la newsletter GET17, rangées par édition (`AAAA-MM/`). Les fichiers y sont déposés par le générateur de newsletter : JPEG de 1 200 px de large au plus, moins de 200 Ko, sans métadonnées.

## Règles

- **Données de démonstration uniquement** : aucun client réel, aucune donnée personnelle. Le générateur demande de le confirmer avant chaque envoi.
- **Ne jamais supprimer ni renommer** un fichier déjà utilisé dans un envoi : les emails reçus continuent de l'afficher. Le générateur ne retire un fichier que s'il n'est utilisé par aucune newsletter de son historique.
- **Un dépôt public garde tout son historique** : un fichier retiré reste visible dans l'historique Git.
- Noms de fichiers sans donnée sensible (rôle du bloc et identifiant aléatoire), version en suffixe (`-v1`).
- Rien d'autre ici : ni image fixe (dépôt `get17-email-assets`), ni historique, ni donnée, ni clé.
- Toujours utiliser l'URL GitHub Pages, jamais `raw.githubusercontent.com`.
